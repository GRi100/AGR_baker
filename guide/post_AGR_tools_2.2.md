## Карточка 1 — ОБЛОЖКА

Надзаголовок: ADD-ONS BLENDER

# AGR Baker v2 — теперь AGR Tools

**AGR Tools** — новое имя аддона. Он давно вырос за пределы запекания:
атласы, UDIM, ренейм, свет, синхронизация, командный буфер — всё в одном.

В этом посте — что нового в 2.2:
• **UDIM** — редактор раскладки тайлов
• **Tile Ops** — замена, конвертация, удаление тайла по клику
• **Библиотека превью** — выбор сетов кликом по картинке
• **Батчи** — Tile ×N, Stub Set, Strip Alpha

Старые сцены совместимы: .blend и настройки подхватываются без миграций.

## Карточка 2 (№1)

# UDIM — тайлы двигаются мышкой

**Edit UDIM Layout** — сетка тайлов с превью прямо во вьюпорте.

Как работает:
1. Выбрал объект с UDIM — нажал кнопку
2. Тащишь тайл в пустую ячейку — переезд
3. Бросил на занятую — тайлы меняются местами
4. **Enter / S** — сохранить, **Esc** — отменить

При сохранении пересобирается всё: файлы текстур, UV островов,
mapping.json. Навигация не блокируется — колесо и зум работают.

## Карточка 3 (№2)

# Операции с тайлами — по клику

Тот же принцип: открылась сетка превью — кликнул тайл — готово.

• **Replace Tile** — заменить текстуры тайла выбранным сетом.
Недостающий ERM соберётся из отдельных карт сам
• **Convert Tile** — вытащить тайл в отдельный сет S_*.
ERM распаковывается на Emit / Roughness / Metallic
• **Delete Tile** — удалить тайл. Если на него смотрят UV —
попросит подтверждающий второй клик

UDIM при этом остаётся целым — правится только то, во что кликнул.

## Карточка 4 (№3)

# Библиотека превью сетов

**Библиотека превью** — все сеты проекта картинками во вьюпорте.

• Клик по превью — выбор, синяя рамка
• Протяжка с зажатой кнопкой — выбор пачкой
• Бейдж разрешения на каждой карточке
• Окно тянется за уголок, как окно тайлов

Список сетов тоже переехал: без чекбоксов — клик по строке,
поиск по имени, фильтры, режим галереи с крупными превью.

## Карточка 5 (№4)

# Новые батч-операции

Работают со всеми отмеченными сетами сразу:

• **Tile ×N** — растайлить текстуру: N×N копий в одной карте,
разрешение растёт в N раз. Новый сет S_*_tileNx
• **Stub Set** — заглушка 256px со средним цветом сета
(альфа не учитывается в среднем — прозрачное не темнит)
• **Strip Alpha** — убрать пустой белый альфа-канал из PNG.
Умеет сам при каждом Refresh
• **Mirror** — зеркальные копии с корректным флипом нормалей

Оригиналы не трогаются — всё пишется в новые папки S_*.

# Интерфейс — теперь как родной

Панели пересобраны под нативный стиль Blender:

состояние помнит сам Blender

Внутри всё то же: Scene-свойства и имена не менялись,
командные пайплайны и старые .blend работают как раньше.
